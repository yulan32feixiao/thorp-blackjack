# 索普21点计算室

一张诚实的 21 点牌桌，外加一台按 **Thorp (1961), PNAS 47:110–112** 现算期望的机器。

**在线试玩 → https://yulan32feixiao.github.io/thorp-blackjack/**

## 它不查表

页面里没有任何硬编码的策略表。每次决策都从当前剩余牌堆 `Q(I)` 重新跑一遍四层倒推：

```
庄家终局分布 → 停牌期望 → 要牌期望（倒推最优）→ 加倍／分牌 → 取最大值
```

连「偏离基本策略」这个判断都是算出来的：开靴时用完整牌堆组成跑一遍同样的引擎当基准，每次决策和它对比。

## 公平性

- 洗牌用 `crypto.getRandomValues` 的 Fisher–Yates（带模偏置剔除）
- 开靴时对整个牌序做 **SHA-256 承诺**，随时可验证牌序未被改动
- **决策函数只接收已公开的牌**，代码层面拿不到牌靴数组
- 庄家暗牌不计入 `Q(I)`，且在庄家回合前对所有人（包括庄家自己）都盖着
- 页面**不发任何网络请求**，没有模型——同一副牌堆必定给出同一个决定

## 验证

引擎在 200,000 手模拟中跑出基本策略 **−0.43%**，教科书六副牌值是 −0.4%～−0.5%。
论文 Table 1 的十个「抽走四张」数据点，复现偏差均在 0.5 个百分点内。

## 玩法

- **座位**：每个位子可设为真人 / 算牌程序 / 基本策略电脑 / 空位
- **实验局**：全场都是程序时可「快跑」上万手，直接看长期趋势
- **辅助开关**：关闭后建议、计数、期望全部隐藏，程序照常运行
- **止损线**：亏掉设定比例后自动离桌

## 数据

对局记录用 `localStorage` 存在**你自己的浏览器里**，不上传、不共享。换设备或清缓存就没了。
